# Modular DJ Controller - ESP32

Projeto de controladora DJ modular utilizando ESP32.

## Objetivo

Construir uma controladora DJ modular inspirada no VirtualDJ com:

- Decks independentes
- Jog wheel customizado
- Iluminação RGB endereçável
- Mixer central
- Comunicação entre módulos
- Expansão futura para modo standalone

## Hardware atual

- ESP32 DOIT DevKit V1
- WS2811 RGB
- Encoder incremental
- Botões táteis
- Impressão 3D + resina

## Funcionalidades implementadas

- SHIFT
- TAP / HOLD / LONG HOLD
- Deck Toggle (A/B)
- Jog Wheel
- Browser Mode
- RGB Deck Feedback

## Roadmap

- PLAY
- CUE
- SYNC
- LOOP
- MIDI VirtualDJ
- Comunicação entre módulos
- Display Mixer
